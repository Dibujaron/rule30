## 1. The problem, seen from outside

Take the map on bi-infinite rows of bits that sends `b` to `b'` with
`b'(i) = b(i-1) XOR (b(i) OR b(i+1))`, and iterate it from the row that is `1`
at the origin and `0` everywhere else. What grows is a triangle of bits, one
row per step, widening by one cell on each side. Write `c(t)` for the bit at
the origin after `t` steps. Known (Jen 1990): no two distinct vertical lines of
this triangle can both be eventually periodic. Known: `c` passes every
statistical test anyone has run, to great depth. Not known: whether
`c` is eventually periodic. The statement in front of me is the implication —
**if `c` repeats, then some other vertical line repeats too** — which together
with Jen's result says `c` never repeats, the first of Wolfram's three prize
questions. Nobody has a route.

**Restated in this vantage's own terms.** Read each row backwards from its
rightmost non-zero cell and call the bit at distance `d` from that end the
*depth-`d` digit*; write `e(t)` for the whole infinite string of digits of row
`t`. Because the rule reads only a cell and its two neighbours, the first `d+1`
digits of `e(t+1)` depend only on the first `d+1` digits of `e(t)`: the digit
string evolves by a *triangular* map `E`, one that changes each digit by a
function of the digits before it. A triangular map is a bijection at every
depth, so `(e(t))` is a purely periodic orbit at every depth, with period a
power of two — the system is an inverse limit of finite cyclic rotations, i.e.
an odometer-like `Z_2`-action, and going one depth deeper is a `Z/2`-extension
of the rotation below, an Anzai skew product whose cocycle is a `Z/2`-valued
function on the finite base. The period doubles at depth `d` exactly when that
cocycle is not a coboundary. And the centre column is
**`c(t) = ` the depth-`t` digit of `e(t)`**: the diagonal of the orbit. So the
residual asks whether the diagonal of an orbit of a `Z_2`-action on a Cantor
set can be eventually periodic while every one of the triangle's other vertical
lines is not. The catch, which is the whole of this document, is that the
diagonal is not a continuous observable: at time `t` it reads depth `t`, so it
escapes every level of the tower.

### 3.2 The coboundary equation between two columns: a sufficient condition for the wall that is strictly weaker than periodicity of a column

**The claim.** The residual does not need a second *periodic* column. It needs a
second column **cohomologous** to the centre one: if for a single pair `(j, x)`
with `x ≠ 0` the difference sequence

```
d_{j,x}(t)  =  centerColumn t  XOR  evolve (t + j) x
```

is eventually periodic, then the wall falls. This is strictly weaker than any
statement on the board, it is a statement about the seed's own picture with no
hypothesis attached, and it is exactly the coboundary equation of the vantage:
two fibres of the same extension differing by a coboundary.

**The dictionary.**

| This project | Cocycles over a base | Checked |
|---|---|---|
| `centerColumn` | The fibre coordinate over the base point at time `t` | — |
| `column initialConfig x`, `x ≠ 0` | Another fibre coordinate of the same extension | — |
| `d_{j,x}(t) = c(t) XOR cell(t+j, x)` | The **difference of two fibre coordinates**: the candidate coboundary | — |
| "`d` is eventually periodic" | "the two fibres are cohomologous, with a transfer function that is eventually periodic" | — |
| The residual's conclusion | `c` eventually periodic **and** `d` eventually periodic ⟹ column `x` eventually periodic | trivial once stated |
| The special case `x = j = L`, `L` a common period of the tower | `d_L(t) = Σ_(i=1..L) g_t(i)`, a **Birkhoff sum of the level cocycle over a window of fixed length `L`** | by `rightDiagonal_recurrence` |
| `d_L ≡ 0` | The tower's periods are bounded by `L`; then column `L` **is** the centre column shifted (3.3) | 276,402 instances |
| Where `d_L` turns on | At `t ≈ K(L)`, the last depth with period `≤ L`: `t = 1, 3, 4, 6, 7, 9, 15` for `L = 1, 2, 4, 8, 16, 32, 64` against `K = 0, 2, 3, 5, 6, 8, 14` | measured |
| Density of `d_L` | `0.75, 0.38, 0.42, 0.47, 0.49, 0.50, 0.50` for `L = 1..64` — it goes to a coin as `L` grows | 60,000 terms |

**Seams.** (i) This is a *sufficient* condition, and the sweep below says it is
false for every small `(j, x)`; its worth is that it is the weakest sufficient
condition anyone has written down for this wall, not that it looks true.
(ii) The `L`-family is a genuine Birkhoff sum over a *fixed-length* window,
which is the improvement over `explorer/portage_odometer.mjs` section C (there
the window grows like `k/2`); but the summand `g_t` changes with `t`, so it is
still not a Birkhoff sum of one function over one transformation. (iii) The
identity `d_L(t) = Σ g_t(i)` is a re-derivation of "columns evolve by the
rule", so no new information enters — the value is entirely in the *shape* of
the statement.

**What it leans on.** Nothing outside the project for the implication itself,
which is two lines. For the language: the coboundary definition fetched at
<https://arxiv.org/html/2603.25069>, quoted in 3.1. For why a cohomological
relaxation is the natural weakening: same source, Theorem 3.12 — *"for
integer-valued cocycles on minimal cascades, the cocycle is a coboundary if and
only if the set {h(n,a) : n ∈ ℤ} is bounded for some point a"* — the classical
statement that being a coboundary is a *boundedness* condition on Birkhoff
sums rather than a periodicity condition.

**The test.** `explorer/portage_cocycle.mjs` section H. All 1,616 sequences
`d_{j,x}` for `x ∈ [-24, 24] \ {0}`, `j ∈ [-8, 24]`, tested for a period
`p ≤ 4096` holding from `t = 20,000` all the way to `t = 60,000`: **none**. The
longest run of *any* period `p ≤ 256` past `t = 20,000` is 17 steps
(`x = -22, j = 7, p = 129`). The diagonal family `d_L` for
`L = 1,2,3,4,5,8,16,32,64` tested for a period `p ≤ 16,384` on `[30,000,
60,000)`: none. For a theorist, the statement to put on the board:

> `centerColumn_other_of_cohomologous_column`: for `x : ℤ` with `x ≠ 0` and
> `j : ℕ`, if `IsEventuallyPeriodic (fun t => xor (centerColumn t) (evolve (t + j) x))`
> and `IsEventuallyPeriodic centerColumn`, then
> `IsEventuallyPeriodic (column initialConfig x)`.

That one is provable in a few lines (an lcm of the two periods; the board
already has `isEventuallyPeriodic_common_period` and `isEventuallyPeriodic_shift`)
and is the *enabling* lemma. Its signature, written out with
`IsEventuallyPeriodic` unfolded, elaborates:
`explorer/portage_scratch_evendriver.lean`. The hard companion, and the thing worth a session, is any
unconditional statement about one `d_{j,x}`.

**What it would give.** It touches the residual directly: it is the only route
in this document that would close it. What would remain: everything, since
proving one `d_{j,x}` eventually periodic looks exactly as hard as the wall —
except that it is a statement about a *difference*, and a difference is the
object every cohomological technique in this vantage's field is built to
handle, while "a column repeats" is not.

### 3.3 If the right-diagonal periods are bounded, the wall falls outright — so a proof may assume the tower is ergodic infinitely often

**The claim.** Suppose the right diagonals share one period `L`. Then column
`L` **is** the centre column shifted down by `L`, cell for cell, and the
residual is immediate. So a proof of the wall may assume, for free, that the
tower's period grows without bound — in the vantage's language, that the Anzai
extension is ergodic (the cocycle is not a coboundary) at infinitely many
levels.

**The dictionary.**

| This project | Over there | Checked |
|---|---|---|
| `PeriodicFrom (rightDiagonal k) L 0` for every `k` | The `Z_2`-action generated by `E` factors through `Z/L`: the closure of `⟨E⟩` is finite | hypothesis |
| Then `rightDiagonal k L = rightDiagonal k 0` | The orbit returns after `L` at every depth | — |
| i.e. `evolve (k + L) L = centerColumn k` | Column `L` is the diagonal read, shifted | 276,402 instances of the unconditional version, 0 failures |
| So column `L` is eventually periodic if `c` is | The two fibres coincide up to a shift | — |
| The actual picture | `σ_k = 1` at `k = 3,4,6,7,9,15,16,24,25,27,29,34,36,37,39` — 15 doublings below `k = 40`, `P_40 = 2^16` | measured |
| So the hypothesis is (measurably) false | The closure of `⟨E⟩` is `Z_2`, not a finite cyclic group | — |

**Seams.** The single seam is that the hypothesis is false in fact, so this
closes the branch of a case split that reality does not take. It is worth
having anyway for the same reason a base case is worth having: it says the wall
is *entirely* a statement about the unbounded-period regime, and it converts
"the periods grow" from a measured curiosity into a hypothesis a proof is
entitled to use.

**What it leans on.** Only `rightDiagonal_periodicFrom_pow`, on the board, plus
the hypothesis. No outside source.

**The test.** The unconditional half is `explorer/portage_cocycle.mjs` section
B: `evolve (k+X) X = centerColumn k` whenever `P_k ∣ X`, 276,402 instances at
`k ≤ 35`, `X ≤ 100,000`, 0 failures. To falsify the conditional statement:
impossible, it is two lines; to make it useless, show the periods are
unbounded, which is what the measurement says and what nothing proves.

**What it would give.** A standing hypothesis. Every attack on the residual may
now assume `σ_k = 1` infinitely often. Nothing on the board uses that, and it
is exactly the hypothesis an ergodic-theoretic argument would want.

### 3.4 The vantage's question, answered: the transient part is not a cocycle over the settled part — it carries the entire configuration-dependence, and the settled part carries none

**The claim.** Split the telescoped sum of `explorer/portage_odometer.mjs`
section C at the seam into a settled parity `A(k)` and a transient parity
`B(k)`, so that `c(k) = A(k) XOR B(k)`. Then `B` is **not** a function of the
settled data, in the strongest sense available: across five different
configurations white far to the left, the settled cells are *identical* —
108,528 out of 108,528, for every one — while the centre columns are unrelated
at every offset. Every bit by which one configuration's centre column differs
from another's lives in `B`. A cocycle must be a function of the base point;
`B` is not, so it is not a cocycle over the settled system, and there is no
skew product to build.

**Seams.** (i) The measurement is of the *seed's* seam constant `0.25`; a
different cut moves a few terms across, and I did not test whether some other

configurations and `c` is not, no cut can, which is the argument rather than
the measurement. (ii) `A` being universal is inherited from obstruction 5 and

**What it leans on.** Nothing outside the project. Obstruction 5's translation
integer `N` was re-derived independently here by maximising agreement over

**The test.** `explorer/portage_cocycle.mjs` sections D and E. To falsify:

a structural reason rather than a computational one. What survives is the
narrower skew-product structure of 3.1, which lives entirely on the right edge
and has nothing to do with the settled region.

### 3.5 The observable is at depth `t`: why the odometer sees nothing, and why every Birkhoff-sum attack on this wall has the same seam

**The claim.** All of it — the odometer factor, the Toeplitz array, the
coboundary machinery, the Birkhoff sums of 3.2, and the settled/transient split
of 3.4 — fails for one reason, and it is the same reason obstruction 1
("index 0 is in the transient of every left diagonal") and obstruction 3 ("the
count measures the horizon") fail. **A cocycle, a coboundary, a Toeplitz
period, a continuous factor: every one of them is a function of finitely many
coordinates of a point in a compact space. The centre column at time `t` reads
coordinate `t`.** On the one base where `c` *is* a fixed continuous observable
— the configuration space, `φ(x) = x_0` — the map is rule 30 itself, which has
positive entropy and no equicontinuous structure. On the one base that *is* an
odometer — the right edge — `c` is not a continuous observable at all. There is
no third base, and I claim this dichotomy is the honest content of the whole
vantage.

**The dictionary.**

| This project | What a cocycle argument needs | Checked |
|---|---|---|
| `centerColumn t = e(t)_t` | A **fixed** `φ` with `c(t) = φ(T^t x)` | — |
| Reading the edge at any fixed depth `d` | A continuous `φ` on the odometer factor | predicts `c` at `0.4977–0.5012` for `d = 1..40` |
| Reading the *whole* level-`n` factor, optimally | The best possible continuous `φ` at level `n`: any function of `t mod 2^n` | held-out `0.4941–0.5046` for `n = 1..14` |
| The level the odometer reaches by time `t` | `2^(0.41 t)` states, i.e. depth `0.41 t` — but `c` reads depth `t` | measured |
| The array `(t, d) ↦ e(t)_d` | Periodic in `t` at every fixed depth `d` — Toeplitz-*shaped*, but see the seam | `rightDiagonal_periodicFrom_pow` |
| Is `c` itself Toeplitz? | Would give an odometer factor of `c` and a whole theory | **No**: `0/2000` positions `t` admit any `p ≤ 4096` with `≥ 40` confirmations, to `t = 200,000` |
| Balance on residue classes | A non-trivial continuous factor would show as bias | max `|density − 1/2|` is `0.0018, 0.0030, 0.0055, 0.0141` at `m = 2, 4, 8, 16` — chance |
| Kopra's dictionary (held source) | The base where `φ` **is** continuous | that base is rule 30, positive entropy |

**Seams.** (i) I did not check whether the odometer is the *maximal*
equicontinuous factor of anything here; I only measured that it predicts
nothing. (ii) **The word "Toeplitz" is used for two different things above and
they must not be confused.** The definition I fetched indexes periodicity by
*position*: `x` is Toeplitz when every position `v` has a finite-index subgroup
of periods. Our right-edge array is periodic in `t` at every fixed *depth* `d`,
which is a different condition — the period subgroup of a single cell `(t, d)`
is generated by `(P_d, 0)` and has infinite index in `Z^2`, so the array is not
a Toeplitz array in the quoted sense. What the two share is the consequence
that matters, an inverse limit of finite rotations sitting underneath; what
they do not share is the theory, so Markley–Paul's characterisation does not
apply here and I do not invoke it. The one place I use the word literally is
the test on `c` itself, which is a 1-D Toeplitz test in the standard sense and
which `c` fails. (iii) "No third base" is a claim about what I could find, not
a theorem — a genuinely new base would be a discovery, and naming that as the
missing object is the most useful thing in this section.

**What it leans on.** The Toeplitz definition and the odometer characterisation,
fetched at <https://arxiv.org/html/1706.05632>: *"We say that x∈Σ^ℤ^d is a
Toeplitz array if for all v∈ℤ^d, there exists a finite index subgroup Z⊆ℤ^d…
such that v∈Per(x,Z)"*, and *"Markley and Paul showed that these flows were
exactly almost one-to-one extensions of odometers, or the group of p-adic
integers."* The `Z`-valued boundedness criterion at
<https://arxiv.org/html/2603.25069>, Theorem 3.12, quoted in 3.2, is the
statement whose `Z/2` version is vacuous.

**The test.** `explorer/portage_toeplitz.mjs` and
`explorer/portage_cocycle.mjs` sections F and J. **A warning that belongs in
the record**: my first Toeplitz test reported `2000/2000` — a perfect pass —
and was worthless, because with periods up to 8,192 against a depth of 60,000
each candidate period is confirmed only about seven times, and a coin passes
that. Rerun to depth 200,000 with a stated minimum number of confirmations and
a xorshift control, the answer is `0/2000` at every setting. The first number
was true about what it measured and false about what I read into it. (The
control also had to be replaced: bit `k` of a linear congruential generator
modulo `2^32` has period `2^(k+1)` and passes the Toeplitz test itself.)

**What it would give.** Nothing directly; it forecloses a family. Concretely,
three attacks are dead after it: "the centre column is Toeplitz, so it has an
odometer factor"; "approximate `c` by continuous observables of the edge and
pass to the limit"; and "`c` is a Birkhoff sum, so use a cocycle rigidity or
equidistribution theorem". What it points at is the one object that would
revive all three: **a compact system, other than the full configuration space,
on which the centre column is a fixed continuous observable.** I could not find
one and I do not know that none exists.

## 4. Died in translation

- **Generalized Morse sequences (Keane 1968), the `b × b̄` construction.** The
  right side produces exactly the right raw material — at every new period the
  word is `u` followed by `ū`, verified at all 16 doublings below `k = 40`, and
  that antiperiodicity is *forced* by the transfer function failing to close.
  But Keane's construction needs the blocks to **nest**, `w_(n+1) = w_n · w̄_n`,
  and they do not: nesting holds at `n = 0, 1` and fails at every level from 2
  to 15. Worse, the first half of `w_(n+1)` is not even a shift or a
  complemented shift of `w_n`. So the tower produces Morse-shaped blocks with
  no Morse sequence at the end of them. Seam: each level restarts the word
  rather than extending it. (The Keane reference itself is **UNVERIFIED**:
  <https://link.springer.com/article/10.1007/BF00531855> redirects to a
  Springer authentication URL, and
  <https://www.esi.ac.at/preprints/esi2068.pdf> returned an unextractable PDF;
  I searched *"Keane 1968 generalized Morse sequences block product b times b
  bar odometer skew product"* and *"generalized Morse sequences are group
  extensions of odometers Z_2 cocycle Lemanczyk Kwiatkowski spectral"*, both of
  which return the `B × C` block-product definition in snippets I could not
  fetch.)
- **Schmidt's essential values and the bounded-Birkhoff-sum criterion.** The
  cleanest theorem in the vantage's field — a cocycle is a coboundary iff its
  Birkhoff sums stay bounded — is vacuous here, because the fibre is `Z/2` and
  every `Z/2`-valued sum is bounded. I looked for a `Z`-valued lift (count the
  black cells rather than their parity) and could not find one that is a
  cocycle over anything: the discrepancy `Σ_(s<t) c(s) − t/2` is a sum over
  time, and there is no base transformation for which `c` is the summand. Seam:
  the same depth-`t` problem as 3.5.
- **`H^1` of the odometer with `Z/2` coefficients.** Continuous cocycles on an
  odometer are locally constant, so each factors through some `Z/2^n` and its
  class is a single bit: the parity of its sum. That is exactly the doubling
  bit `σ_k`, which is satisfying — the doubling law *is* a cohomology class —
  and it is also the end of the road, because the whole cohomology group is
  `Z/2` per level and the wall needs `t` bits at time `t`.
- **`B` as a coboundary with a structured transfer function.** Over `Z/2` every
  sequence is a coboundary of *something* (take the running XOR), so the
  question is whether the transfer function is structured. The running XOR of
  `c` has density `0.5027`, shift agreements `0.4974–0.5045` at all powers of
  two to `2^10`, and no period `≤ 4096` from `t = 20,000` to `60,000`. Seam: a
  coboundary equation with no regularity demanded on `ψ` is not a constraint.
- **The settled region as a base for a skew product.** 3.4 is the death
  certificate: the base is identical across configurations and the fibre is
  not, so `B` is not a function of the base and there is no skew product.
  Recorded here as well as in section 3 because the next connector should not
  re-run it: the settled data is *universal*, so any statistic of it is
  universal, so it cannot separate two configurations whose centre columns
  differ — and that is a two-line argument, not a measurement.
- **The centre column as a Toeplitz sequence.** Would have handed over an
  odometer factor and Downarowicz's whole toolbox. `0/2000` positions, to depth
  200,000. Seam: the array `(t, depth)` is Toeplitz and the centre column is
  its diagonal, and a diagonal is not a point.
- **Identifying the three-state automaton in the published classification.** I
  have `E` as an explicit invertible three-state Mealy automaton over two
  letters (`q0 = (q0,q2)`, `q1 = σ(q0,q2)`, `q2 = σ(q1,q2)`) and the
  classification of the 194 minimal such automata exists
  (<https://arxiv.org/abs/0803.3555>), but I could not fetch a table of the
  automata to match ours against, only the abstract. Left as a concrete,
  bounded task for whoever picks this up: identify the class, and ask whether
  the group is contracting — if it is, Nekrashevych's limit space is a genuinely
  new object attached to rule 30.
- **`E` as the odometer proper.** It is not: the order of `E` at level 14 is
  256 while the seed point's orbit is 64, so `E` is not level-transitive. This
  refines the death recorded in my first sighting (where I killed the odometer
  conjugacy at `m = 2` by a collision); the reason is now structural rather
  than a collision — `E` is a thin element, not a transitive one.
- **The accumulator `1/(1+D)` of stream-cipher design.** The right recurrence
  is literally one integrator over `GF(2)`, and the "output period doubles iff
  the input has odd weight per period" rule is that field's folklore. It buys
  the same single fact as the wreath product and stops at the same place: the
  input is an `OR`, so there is no transfer-function algebra past one division,
  and no linear-complexity argument applies. Kept as a row because it is a
  cheaper vocabulary for the same theorem if a theorist prefers it.
- **The wreath-product argument as a route past obstruction 7.** I thought for
  an hour that the tower's group theory would give the non-doubling half of
  `rightDiagonal_period_doubles_iff_odd_weight`. It does not, and the reason is
  exactly obstruction 7's: group theory bounds the **common** period of the
  first `k` diagonals and says nothing about whether an individual diagonal has
  a *shorter* period than its neighbours. What it does give is that the common
  period is `Q` or `2Q` and never anything else, which is section 5's topic 1
  and sidesteps the obstruction instead of overcoming it.
- **Anzai skew products as a single system.** The extension at depth `k` is an
  honest Anzai skew product, but the base is `Z/Q_k` and changes at every
  level, so the tower is a sequence of skew products, not one skew product with
  a cocycle to study. Every theorem in the Anzai literature I could reach is
  about a *fixed* base with an irrational rotation. Seam: our base is finite
  and grows.
- **Bratteli–Vershik, `Aut(T_2)` on the left, Cobham, Iwasawa `μ` and `λ`,
  Artin–Schreier, skew products over `Z/p`.** All killed in my first sighting,
  in its section 4, at seams that this vantage does not change. Not re-tried.

## 5. What to hand the theorist

**Topic 1 (the one I would spend the session on). Restate the right-diagonal
doubling criterion about the *common* period, where it is provable, instead of
the *minimal* period, where obstruction 7 says it is not.** The board has
`rightDiagonal_antiperiodic_of_odd_driver` (the odd branch, including
`¬ PeriodicFrom L 0`) and treats the even branch as hard. The even branch is
hard only as a claim about minimality. As a claim about a period it is three
lines: by `rightDiagonal_recurrence`, `R_(k+2)(j + L) = R_(k+2)(j) XOR Σ_(i=1..L)
g(j+i)`, and `g` has period `L` because the two diagonals feeding it do, so
that sum is the same for every `j` and equals the weight parity. Hence

> `rightDiagonal_periodicFrom_step_of_even_driver (k L : ℕ)`
> `(hL0 : PeriodicFrom (rightDiagonal k) L 0)`
> `(hL1 : PeriodicFrom (rightDiagonal (k+1)) L 0)`
> `(heven : Even ((Finset.range L).sum (fun j => if rightDiagonal (k+1) (j+1) || rightDiagonal k (j+2) then 1 else 0)))`
> `: PeriodicFrom (rightDiagonal (k+2)) L 0`

This signature elaborates as written: `explorer/portage_scratch_evendriver.lean`,
`lake env lean`, only the `sorry` warning. It is the exact mirror of the odd lemma, sharpening `rightDiagonal_periodicFrom_step`
from `2 * L` to `L`. With it, the common period `Q_k` of all diagonals to depth
`k` is a power of two that doubles exactly at the odd-weight levels and is
otherwise unchanged, and *that* is the object the tower actually runs on: it is
the orbit period of the right-edge automorphism at level `k` (dictionary row 10
of 3.1, measured to level 15 by two independent implementations that agree
exactly). The depth that would settle it: none — it is a proof, not a
measurement, and the supporting identities fail 0 times on 39 levels. The one
thing to check first, because it would make the topic pointless: whether the
board already wants `Q` and I have missed it; I searched `Rule30/Statements.lean`
and found only the `2 * q` version.

**Topic 2. The coboundary equation as the wall's weakest sufficient
condition.** Put `centerColumn_other_of_cohomologous_column` (3.2) on the
board — it is a few lines — and then ask a theorist to attack, or to record as
an obstruction, the unconditional companion: *is there any `x ≠ 0` and `j` for
which `t ↦ centerColumn t XOR evolve (t + j) x` is eventually periodic?* It
depends on exactly one dictionary row: that a difference of two fibres is the
natural cohomological object, where "a column repeats" is not. The depth that
would settle it in the negative direction is already run — 1,616 pairs, no
period `≤ 4096` surviving from `t = 20,000` to `60,000`, longest partial run 17
steps — so what a theorist can add is either an obstruction (a reason no
difference can be eventually periodic, which would be a real theorem and might
follow from Kopra's width-2 result) or the observation that the free companion
`centerColumn_other_of_rightDiagonal_period_bounded` (3.3) closes the
bounded-period branch and so licenses assuming the periods grow.

## 6. Next vantage

**Algebraic and expansive subdynamics of `Z^2` actions** — Boyle–Lind
directional expansiveness, Kitchens–Schmidt, Ledrappier-type `Z^2` subshifts.
I named it last time as the vantage I could not reach, and this session has
made the case for it sharper rather than weaker: the reason every object in
this document fails is that the centre column is read at a depth that grows
with time, which is precisely the statement that the vertical direction is not
one of the directions in which this `Z^2` array is expansive or periodic, while
the two diagonal directions are. Directional expansiveness is the theory built
to say which directions in a space-time diagram carry the information, and the
picture hands it three measured slopes nobody has related — the seam at
`0.25 t`, the damage front at `0.24 t`, and the period exponent `2^(0.41 k)` —
in a setting where one diagonal direction is exactly periodic with no
transient and the other is eventually periodic. A connector coming from there
should be handed the identity `centerColumn t = e(t)_t` from 3.1 and asked
whether "the diagonal of a Toeplitz array" has a name in that field.

The vantage I could not reach from where I stood is **contracting self-similar
groups and Nekrashevych limit spaces**. I have the three-state automaton
explicitly and I could not determine whether the group it generates is
contracting, which is the gate to everything in that theory: a nucleus, a limit
space, an iterated monodromy interpretation. That is a bounded, concrete
computation — build the nucleus of `⟨q0, q1, q2⟩` and see whether it is finite
— and it needs somebody who knows the machinery rather than somebody who has
just met it. If the group is contracting, rule 30's right edge acquires a
compact limit space that no one has looked at, and the question of what the
diagonal `t ↦ (E^t δ)_t` means on it is the first thing to ask there.
