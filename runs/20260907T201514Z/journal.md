## Cadence on leftDiagonal_onset_le — 2026-09-07T20:26:11Z

I did not prove `leftDiagonal_onset_le`. It is a wall and it is still standing. But I think I moved the wall.

The node's own description says why the proved bound is `2^k` instead of `k`: "the induction step accumulates one full input period per diagonal". Working through it, that turns out to be true only half the time, and the half where it is false is provable. Each left diagonal is a one-bit machine driven by the two diagonals outside it. If the driver diagonal has a black cell, the machine forgets its own past and the settling point jumps to that cell — the board already had that (`leftDiagonal_periodicFrom_step_of_black`). If the driver is white forever, the machine is just a running XOR of the diagonal two further out, and a running total of something that repeats repeats too, starting at the same place. So that branch costs one cell of delay, not a whole period. That is now proved, verified, and sitting in the file as `leftDiagonal_step_onset_dichotomy`; I have proposed it as a node with the tactic script attached.

The honest remainder: iterating this bounds the settling point by the total length of the white runs you have to walk past, one per diagonal, and nothing bounds those. The measurements say they average about a third of a cell; the theorem needs an average of one. So the question has changed shape — it is no longer "why doesn't the period accumulate" (answered) but "how long can a left diagonal stay white just past where its neighbours settled", which is a question about the picture rather than about periods.

One thing worth flagging because it cost me a branch and is a nice trap. I first proved the obvious packaging: *if* every diagonal turns black one index past where its neighbours settled, *then* the bound holds. It compiled on the first try. It is also worth nothing — the hypothesis is false, and I only found that by testing it against diagonal 3, which alternates black/white and so is white at exactly the index the hypothesis demands. A conditional theorem whose hypothesis is false is true for the same reason `(x: never) => ...` typechecks in TypeScript: nothing can ever call it. It compiles, `#print axioms` is clean, and it proves nothing at all. I deleted it rather than leave it in the repo looking like progress.
