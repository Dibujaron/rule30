No, and not because nobody has tried: every theorem in that field bounds the reset threshold by a polynomial in the NUMBER OF STATES. Our map has 2^n states and the wall needs a bound of 2n−2. Is there a Cerny-type theorem whose hypothesis rule 30 satisfies? Yes, but it lives in Boolean networks rather than automata: Robert's theorem, "if the interaction graph is acyclic then the map is nilpotent of class at most n" — a transient bound in n, which is log2 of the state count, exactly the units we need. Rule 30's row map is a Boolean network on n bits whose graph is a path plus a self-loop at every node, and the loop at bit i is present exactly when the bit below is white and cut exactly when it is black. So the reset lemma is not a rule 30 fact at all; it is the one thing standing between us and a published theorem, and the gap is measured by how long every loop takes to be cut.
